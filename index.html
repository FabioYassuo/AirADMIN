Configuração Inicial
Conecte ao seu banco de dados Supabase para começar. Siga os passos abaixo:
1 Criar conta no Supabase
Acesse supabase.com → clique em "Start your project" → faça login com GitHub ou e-mail → clique em "New Project" → escolha um nome e senha para o banco.
2 Criar as tabelas do banco
No painel do Supabase → vá em "SQL Editor" → clique em "New query" → cole o SQL do arquivo setup-banco.sql que está junto com este arquivo → clique em "Run".
3 Copiar suas credenciais
No painel do Supabase → vá em "Project Settings" → "API" → copie a Project URL e a anon public key e cole abaixo.
Já configurou antes? As credenciais ficam salvas automaticamente. Carregar salvas
